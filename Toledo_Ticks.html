Indicador para calcular a volatilidade das últimas barras em ticks, evite violinadas e aproveite mais os scalps, preparado para Índice, Dólar e Ações, agilidade para você configurar as ordens oco na boleta usando a opção personalizada.

Você ponde alterar o período e o tipo de média para usar.

Período: Informa o número de barras que deseja usar.

Exponencial:
Sim = Usa média exponecial dando peso maior para as barras mais recentes.
Não = Usa média aritimética.

Dica de Ouro: Usar esse indicador junto com o Toledo Pontos para obter mais oportunidades de scalp.
